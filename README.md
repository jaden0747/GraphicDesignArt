# GraphicDesignArt

A public learning log for **2D pixel art**, built as a path toward a career in game and graphic design.

It holds the roadmap, short lessons, weekly exercises, starter palettes, and a practice log. Work through it in order, one week at a time.

## Goals

- Draw readable pixel art at 16×16 to 64×64
- Use limited palettes and hue-shifted shading with confidence
- Animate simple sprites (idle and walk cycles)
- Build a small portfolio of finished pieces with process notes

## How to use this repo

1. Read the lesson for the current week.
2. Do the exercise. Work at 1× zoom as much as you can, because that is how the art will be seen.
3. Save your PNG to `practice/week-XX/` using the naming rule in [practice/README.md](practice/README.md).
4. Fill in your row in [progress/TRACKER.md](progress/TRACKER.md).
5. Commit and push.

## Free tools

- **Piskel**: free, runs in the browser. Good for day one.
- **Libresprite**: free, open-source fork of Aseprite.
- **Aseprite**: paid, the industry standard for pixel art and animation. Available at [aseprite.org](https://www.aseprite.org/).
- **Lospec**: palettes, tutorials, and a palette importer at [lospec.com](https://lospec.com/).

Any of these is enough to start. Pick one and stay with it for a while.
