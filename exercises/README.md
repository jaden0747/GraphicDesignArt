# Exercises

Each week has one main challenge. Use the done-checklist to decide when you're finished. Log each week in [progress/TRACKER.md](../progress/TRACKER.md).

Work at 1× zoom as much as you can. Export your final PNG at its native size, and keep the `.aseprite` or other source file if you have one.

## Weeks 1–2 · Silhouettes and pixel lines

**Week 1 · Icon set (16×16)**
Draw 4 simple icons: a heart, a key, a coin, and a potion.

- [ ] Each icon reads at 1× zoom
- [ ] Each icon passes the squint test
- [ ] Pixel-perfect lines, no stray pixels
- [ ] Uses 4 colors or fewer

**Week 2 · Character silhouette (32×32)**
Draw one character in a single flat color first, then add a basic outline.

- [ ] The silhouette alone identifies the character
- [ ] One outline style, applied everywhere
- [ ] Arms, legs, and head are clearly separated

## Weeks 3–4 · Color and palettes

**Week 3 · Ramp practice (16×16)**
Make 3 ramps of 4 steps each: red, teal, and yellow. Fill a 16×16 grid of swatches with them.

- [ ] Each ramp is evenly ordered from dark to light
- [ ] Shadows drift cool, highlights drift warm
- [ ] Total colors: 12 or fewer

**Week 4 · Limited palette sprite (32×32)**
Pick a palette from [palettes/](../palettes/) and draw a small scene: a tree, a house, or a tool. Use only that palette.

- [ ] Only colors from the chosen palette
- [ ] Hue-shifted shadows
- [ ] No pure black or pure white unless the palette has them

## Weeks 5–6 · Shading and form

**Week 5 · Sphere and cube (32×32)**
Shade a sphere and a cube with one light source.

- [ ] Light comes from the same direction on both
- [ ] Core shadow and highlight are both present
- [ ] No stray single pixels

**Week 6 · Dithering study (32×32)**
Draw a sky or a stone wall that uses dithering in one place only.

- [ ] Dithering appears only where it adds a gradient
- [ ] The rest of the image uses clean shapes
- [ ] You can explain why each dithered area is there

## Weeks 7–8 · Animation

**Week 7 · Idle loop (32×32, 4 frames)**
Animate a breathing or blinking idle loop.

- [ ] 4 frames, looping without a jump
- [ ] The pixel grid stays stable across frames
- [ ] Preview at the target frame rate

**Week 8 · Walk cycle (32×32, 6 to 8 frames)**
Animate a walk cycle, side view.

- [ ] Feet alternate correctly
- [ ] Body bounces on the step
- [ ] Loops without a visible reset

## Weeks 9–10 · Environments and tiles

**Week 9 · Tileable texture (16×16)**
Make a ground or wall texture that tiles seamlessly.

- [ ] Edges match when tiled in a 5×5 grid
- [ ] Detail reads at 1× zoom

**Week 10 · Small tileset (16×16, 9 tiles)**
Make a tileset with corners, edges, and a center tile for one surface.

- [ ] All 9 tiles connect cleanly
- [ ] Same light direction and palette as the rest of your work

## Weeks 11–12 · Game-ready assets

**Week 11 · Sprite sheet**
Export an animation as a sprite sheet with fixed frame size and padding.

- [ ] Frame size is consistent
- [ ] Padding between frames is consistent
- [ ] Files are named clearly

**Week 12 · UI panel and style guide**
Make a 9-slice panel and a button, then write a one-page style guide.

- [ ] Panel stretches cleanly with 9-slice borders
- [ ] Style guide lists: palette, outline rule, light direction, canvas sizes
