# Practice

Put your exported PNGs and source files here, one folder per week.

## Naming

```
practice/
  week-01/
    01-heart-16x16.png
    01-heart-16x16.aseprite
  week-02/
    02-knight-silhouette-32x32.png
```

- Folder: `week-XX`
- File: `NN-short-name-WIDTHxHEIGHT.png`
- Keep the source file next to the PNG when you have one. It lets you revise later.

## Good habits

- Export at native size. Scale up only in a separate preview file.
- Keep a few early pieces. Seeing your progress is motivating.
- Don't delete attempts you didn't like. They show how far you've come.
